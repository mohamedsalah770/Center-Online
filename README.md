# Center Online - منصة سنتر أونلاين التعليمية

منصة تعليمية تفاعلية مخصصة لطلاب المرحلة الثانوية، تقدم تجربة تعليمية متكاملة تشمل فيديوهات الشرح، المذكرات، والاختبارات التفاعلية بنظام التقييم الفوري.

## ✨ المميزات الرئيسية
- **واجهة مستخدم حديثة وسلسة:** تصميم متجاوب يدعم الأجهزة المكتبية والمحمولة (Responsive Design).
- **تجربة تفاعلية متكاملة:** تشمل أسئلة تفاعلية (Quizzes) مع تغذية راجعة فورية.
- **عرض تجريبي للدروس:** محتوى تعليمي منظم ومقسم حسب المواد والمراحل الدراسية.
- **كود منظم ونظيف:** مبني باستخدام HTML5, CSS3, و Vanilla JavaScript دون أي أطر عمل خارجية ثقيلة.

## 🚀 كيفية التشغيل
يمكنك فتح ملف `index.html` مباشرة في أي متصفح ويب، أو استخدام إضافة مثل **Live Server** في VS Code لتشغيل بيئة تطوير محلية.

## 🛠️ التقنيات المستخدمة
- **HTML5**
- **CSS3** (CSS Variables, Flexbox, CSS Grid)
- **JavaScript (ES6+)**
- **Font Awesome 6** للأيقونات
- **Cairo Font** من Google Fonts
